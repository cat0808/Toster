# Островок уверенности

Веб-приложение психологического комфорта для школьников: игры против бота, музыка, видео, фото-слайдер и чат с ИИ-психологом через GigaChat API.

## Возможности
- 5 головоломок против бота с выбором сложности: крестики-нолики, камень-ножницы-бумага, быки и коровы, виселица, угадай число.
- Автозагрузка музыки из `media/music`.
- Автозагрузка видео из `media/videos`.
- Галерея изображений из `media/photos` с переключением и свайпом влево/вправо.
- Чат ИИ-психолога через GigaChat API.
- Фильтр грубых/неподобающих сообщений: бот просит переформулировать вопрос.

## Локальный запуск
```bash
cp .env.example .env
npm run localhost
```
Откройте `http://localhost:3000`.

Для запуска в режиме прод-сервера с доступом извне: `npm start` (сервер слушает `0.0.0.0`).

## Переменные окружения
Смотрите `.env.example`.

Если `GIGACHAT_CLIENT_ID`/`GIGACHAT_CLIENT_SECRET` не заданы, чат работает в безопасном локальном fallback-режиме (без внешнего API), чтобы интерфейс не падал при локальном запуске.

## Prod / деплой на REG.RU

### Вариант 1: Docker (рекомендуется)
1. Подготовьте сервер/VPS на REG.RU с Docker.
2. Скопируйте проект и `.env` на сервер.
3. Соберите и запустите:
```bash
docker build -t ostrovok-uverennosti .
docker run -d --name ostrovok -p 3000:3000 --env-file .env ostrovok-uverennosti
```
4. Прокиньте домен через Nginx (reverse proxy на `127.0.0.1:3000`) и включите TLS (Let's Encrypt).

### Вариант 2: Node.js + systemd
1. Установите Node.js 20+ на VPS REG.RU.
2. Создайте `.env`.
3. Запуск:
```bash
npm start
```
4. Создайте systemd unit для автоперезапуска и Nginx reverse proxy с HTTPS.

## Структура медиа
- `media/music` — `.mp3/.wav/.ogg/.m4a`
- `media/videos` — `.mp4/.webm/.mov/.m4v`
- `media/photos` — `.jpg/.jpeg/.png/.webp/.gif`
