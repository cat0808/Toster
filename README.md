# Мультимедиа сайт (localhost)

Теперь проект запускается как локальный сайт на Flask.

## Возможности

- Увеличены размеры кнопок и улучшена визуальная читаемость элементов управления.
- Палитры тем доработаны (контраст, акцентные цвета, границы).
- музыка (по кнопкам: начать / предыдущая / следующая),
- картинки (по кнопкам: начать / предыдущая / следующая),
- видео (выбор и информация о файле),
- головоломки: Пятнашки, Найди пару, Крестики-нолики,
- ИИ-запросы через GigaChat,
- несколько цветных тем.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Куда класть медиафайлы

Складывайте музыку, видео и изображения в папку `media/` в корне проекта. Подпапки поддерживаются.

Пример структуры:

```text
media/
  music/
    song.mp3
  video/
    clip.mp4
  images/
    photo.jpg
```

Поддерживаемые расширения:
- аудио: `.mp3`, `.wav`, `.flac`, `.ogg`, `.m4a`
- видео: `.mp4`, `.avi`, `.mkv`, `.mov`, `.webm`
- изображения: `.png`, `.jpg`, `.jpeg`, `.gif`, `.bmp`, `.webp`

## Переменные окружения для ИИ

- `GIGACHAT_CLIENT_ID`
- `GIGACHAT_CLIENT_SECRET`

## Запуск сайта

```bash
python webapp.py
```

Откройте в браузере: `http://127.0.0.1:5000`

> Примечание: в демонстрационном коде запросы к API идут с `verify=False`. Для production используйте корректные сертификаты.
