# Мультимедиа приложение (Python + Tkinter)

Приложение с UI, которое умеет:

- воспроизводить музыку,
- выбирать видео и показывать информацию о выбранном файле,
- просматривать картинки,
- решать 3 головоломки: **Пятнашки**, **Найди пару**, **Крестики-нолики (1 игрок против бота)**,
- отправлять запросы в ИИ.

## Что изменено

- Улучшены цветные темы **Фиолетовая** и **Зелёная**.
- Крестики-нолики работают для 1 игрока с рандомным выбором символа игрока (`X` или `O`).
- После победы/поражения/ничьей в крестиках-ноликах статус показывается внутри вкладки; новая игра запускается кнопкой **«Новая игра»**.
- Сообщения о результате в головоломках отображаются в самой программе (без отдельных popup-окон).
- Музыка и картинки теперь идут по очереди кнопками, без списков.
- Добавлены кнопки:
  - **«Начать слушать музыку»**,
  - **«Начать смотреть картинки»**.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка ИИ

Настройки читаются из переменных окружения:

- `GIGACHAT_CLIENT_ID`
- `GIGACHAT_CLIENT_SECRET`

## Запуск

```bash
python app.py
```

> Примечание: в демонстрационном коде запросы к API идут с `verify=False`. Для production лучше настроить валидные сертификаты.
