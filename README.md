# Toster — Telegram-бот для создания контрольных работ

Школьный проект: Telegram-бот, который по названной пользователем теме генерирует контрольную работу с нужным количеством вариантов с помощью нейросети и присылает её готовым PDF-файлом.

## Возможности

- Генерация контрольной работы по любой теме в 2, 3 или 4 вариантах.
- Основная модель — **Google Gemini**, резервная — **GigaChat** (если Gemini не ответил, бот автоматически переключается на GigaChat).
- Преобразование Markdown-ответа нейросети в аккуратный PDF с кириллицей, таблицами, списками и линиями для ответов.
- Хранение пользователей и состояния диалога в SQLite.
- Для каждого пользователя ведётся отдельный чат с Gemini.

## Как это работает

1. Пользователь отправляет `/new_control`.
2. Бот предлагает выбрать количество вариантов кнопками (2, 3 или 4 — рекомендуется 4).
3. После выбора количества вариантов бот предлагает выбрать класс кнопками(1-11)
4. Пользователь пишет тему контрольной.
5. Бот формирует запрос вида «Создай контрольную по теме … в N вариантах» и отправляет его в Gemini. Если Gemini вернул ошибку, запрос уходит в GigaChat.
6. Ответ (Markdown) конвертируется в PDF и отправляется в чат документом. Перед печатью файла стоит проверить на возможные ошибки нейросети.
7. Режим создания контрольной сбрасывается, и можно начать заново.

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Регистрация пользователя и приветствие |
| `/new_control` | Начать создание новой контрольной |
| `/end_control_create` | Завершить режим создания контрольной (сбросить состояние) |

## Структура проекта

| Файл | Назначение |
|---|---|
| `Bot.py` | Точка входа. Обработчики команд, кнопок и текстовых сообщений, основная логика диалога |
| `Aigemeni.py` | Клиент Google Gemini (модель `gemini-3.6-flash`) основная нейросеть |
| `Aigiga.py` | Клиент GigaChat (модель `GigaChat-2-Pro`), используется как запасной вариант |
| `FixPdf.py` | Обёртка `md2pdf` для использования в боте |
| `md2pdf.py` | Конвертер Markdown → PDF на `markdown` и `reportlab` (написан при помощи ИИ) |
| `DataBases.py` | Работа с SQLite: таблица пользователей, количество вариантов, флаг режима создания контрольной |
| `Tokens.py` | Токены и ключи (**не входит в репозиторий**) |
