# Multimedia Hub (Python + Tkinter)

Приложение с UI, которое умеет:

- воспроизводить музыку,
- выбирать видео и показывать информацию о выбранном файле,
- просматривать картинки,
- решать 3 головоломки: **Пятнашки**, **Найди пару**, **Крестики-нолики (1 игрок против бота)**,
- отправлять запросы в ИИ.

## Что изменено

- Из вкладки ИИ убран текст про переменные окружения в описании интерфейса.
- Крестики-нолики адаптированы под одного игрока: вы играете за `X`, бот ходит за `O`.
- Добавлены цветные темы: **Светлая**, **Тёмная**, **Фиолетовая**, **Зелёная**.
- Для всех головоломок есть эффекты завершения (подсветка + сообщение).
- Сканирование файлов выполняется только при запуске приложения.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка ИИ

Настройки читаются из переменных окружения:

- `GIGACHAT_CLIENT_ID`
- `GIGACHAT_CLIENT_SECRET`

## Запуск

```bash
python app.py
```

> Примечание: в демонстрационном коде запросы к API идут с `verify=False`. Для production лучше настроить валидные сертификаты.
